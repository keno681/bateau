DERNIÈRE VAGUE · COOPÉRATION

À cinq, on tient.

Un seul bateau, un équipage partagé. Jusqu’à cinq personnes, hôte compris.

Choisissez Héberger ou Rejoindre.

L’hôte laisse le jeu ouvert et partage son code d’invitation avec les autres joueurs.

Les fichiers du jeu et les modifications Pokéball de l’hôte seront chargés automatiquement dans cette partie.

Équipage

    Pour une connexion locale fiable
    Utilisez la même version du jeu sur le même réseau Wi-Fi ou Ethernet. Le Wi-Fi invité peut isoler les appareils. Si Windows le demande, autorisez le jeu sur le réseau privé.
    La Pokéball de l’hôte met à jour tous les écrans. La connexion reste dans le moteur pendant les redémarrages.
